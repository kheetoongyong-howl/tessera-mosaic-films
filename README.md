# Tessera mosaic films

Two 80-second animated films, each a single HTML file built with WebGL2 and plain JavaScript. There are no libraries and no image, font or audio files.

The wall is a glass and gold-leaf mosaic whose tiles were never glued down. They lift, flip, fly off to form figures, then click back into place.

- `index.html`: **Tessera**. A Byzantine sea-and-sun mosaic. A koi, a school of fish and birds form from the tiles, then the whole wall lifts into a vortex and a golden sunflower before rebuilding itself.
- `central-park.html`: **Central Park Seasons**. The Lake, Bow Bridge and the skyline through a year. Waves of flipping tiles change the season, and seasonal animals and people dressed for the weather form in the frieze around the scene.

Open either file in a browser that supports WebGL2. Each page links to the other.

Controls: click to toggle sound, space to pause, ← → to jump 5 seconds, R to restart.
